# LVLzchk

LVLzchk — веб-приложение для ведения личных и совместных целей. Цели распределяются по доскам и уровням приоритета, а доступ к каждой доске защищён отдельным PIN-кодом.

## Возможности

- создание и администрирование нескольких досок;
- добавление, редактирование, завершение и архивирование целей;
- распределение целей по высокому, среднему и низкому приоритету;
- сортировка карточек и перенос между колонками с помощью drag-and-drop;
- поиск, фильтрация и отдельное отображение завершённых целей;
- подзадачи с ручной сортировкой и учётом их стоимости;
- отслеживание целевой и накопленной суммы с отображением прогресса;
- описания в обычном тексте, Markdown или HTML;
- публикация отдельных целей по уникальной общедоступной ссылке;
- создание целей через API с ключом доски;
- импорт и экспорт целей в JSON.

## Технологии

- PHP 8.5+ и Laravel 12;
- Livewire 4;
- Tailwind CSS 4 и Vite 7;
- SQLite;
- Docker Compose и Nginx.

## Локальный запуск

### Через Docker

```bash
./deploy-local.sh
```

После запуска приложение будет доступно по адресу <http://localhost:8080>.

### Без Docker

```bash
composer run setup
composer run dev
```

Перед первым запуском при необходимости измените в `.env` значения `PIN_CODE`, `ADMIN_PIN_CODE` и `DEFAULT_BOARD_NAME`.

## API: Создание цели

Оформленная документация с примерами доступна на `/docs/api` и по ссылке в настройках доски.

`POST /api/goals` создаёт цель в доске, которой принадлежит API-ключ. 

```bash
curl -X POST 'https://example.com/api/goals' \
  -H 'Authorization: Bearer API_KEY' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  --data '{
    "title": "Купить монитор",
    "description": "Подобрать монитор для работы",
    "priority": 2,
    "target_amount": 30000,
    "tags": ["IVAN", "Работа"]
  }'
```

## Импорт и экспорт

```bash
php artisan goals:export
php artisan goals:import
```

Экспорт включает доски и цели. Импорт принимает файлы экспорта и восстанавливает привязки целей к доскам независимо от их ID в новой базе.

По умолчанию обе команды используют файл `storage/app/goals_export.json`. Другой путь можно передать первым аргументом; для очистки существующих целей перед импортом предусмотрен флаг `--truncate`.
